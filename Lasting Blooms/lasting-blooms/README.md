# Lasting Blooms by Malaki

A multi-page website for a small flower shop. It has a home page, a shop page with a cart, an about page and a contact page.

## Technologies used
- HTML5
- CSS3 (flexbox, grid and media queries)
- JavaScript

## Main features
- Navbar on every page, with a menu button on small screens
- Shop page with a search box
- Hero section , containing title and brief explanations along side with quotes on the left while hero image ( flower and friend) on the right.
- Simple cart: add, remove, clear, and a total price (saved with localStorage)
- Contact form with validation.
- Responsive layout for desktop, tablet and mobile
- Animated Background (Assisted)
- 

## How to open it - Instrucions
- download or copy the folder
- open it in VS code or your personal IDE
- Make sure of all the contents are organized well and in their correct folder, especially images.
- Launch the Web through index.HTML


## Folder structure
- `index.html`, `shop.html`, `about.html`, `contact.html` - the pages
- `css/style.css` - all the styling
- `js/script.js` - menu, cart, search and form code
- `images/` - the logo and product pictures
